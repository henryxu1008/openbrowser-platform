# 硕米用户的原生安装与登录

本批实现待 PR 审阅，尚未发布安装包或部署；正式目标实例的公开配置由发布前核对确定。

## 用户操作

下载安装包并完成安装，从开始菜单或桌面图标打开浏览器，点击现有“通过浏览器登录”，在硕米现有身份服务中完成本人登录，再回到浏览器使用。结束时正常退出，以后点击同一图标继续使用原数据。用户不需要 PowerShell、OIDC 参数、环境变量或本地 Docker。

沿用原生 PKCE 登录、内存会话、注销与业务准入；不会创建身份或改变硕米 IAM。安装程序不以管理员身份自动打开应用，安装后通过普通快捷方式启动。

## 发行配置（维护者）

打包者从目标硕米实例取得已有 Native public client 的 issuer/clientId，仅这两项公开元数据。Web client secret、账号、密码、token、私钥不得进入发行文件。不重新注册客户端，不把 Web client ID 当 Native client 使用。

程序从 EXE 同目录的 `oidc-public.json` 读取公开配置；文件存在时优先使用它，读取/格式错误则保留原有未配置登录界面并拒绝业务操作，不能回退为其他身份配置。文件不存在时保留历史开发环境变量入口。该文件位于安装目录，不与用户可写业务配置混存。

Windows 原有打包入口增加一个维护者参数；打包工具使用 PowerShell 7，用户端没有这项依赖：

```powershell
.\bat\publish.ps1 -Target WINDOWS -WindowsFormat INSTALLER -PublicIdentityConfig 'C:\发行配置\oidc-public.json'
```

公开文件结构（示例地址仅说明格式，不能代替目标实例配置）：

```json
{"issuer":"https://identity.example.test","clientId":"existing-native-public-client"}
```

打包前拒绝缺失、重复/额外字段、secret、HTTP 及 loopback 开发地址，复制为原生可读取的 UTF-8 文件，再由现有 NSIS 安装到 EXE 旁边。既有内核与代理资源打包逻辑不变；缺少内核时沿用原内核管理，版本需求仍为 148.0.7778.215，不增加下载器、服务或固定清单。

只读核对的本机硕米实例为 `https://localhost:35443`，与既有 Native client 和公开 discovery 相符，支持 S256；这些是本地验收配置，不作为用户发行默认。外部发行目标依用户决定在发布前确定，本批不调用登录/管理接口、不改 IAM。

## Windows 用户数据

注册安装版本（包括自选安装目录）和 Program Files 下的安装使用 `%LOCALAPPDATA%\ant-browser` 保存配置、SQLite、档案和可写内核目录。安装目录的 `bin` 继续用于随包代理运行时。路径选择不因提权、当前工作目录或升级安装路径变化而改变；可写便携目录保留原有就地数据行为。

应用按状态根取得现有单实例锁后才初始化布局。首次切换目录时，沿用 copy-if-missing 复制缺失的目标；源不删除，已有目标不覆盖。只有旧 SQLite（不存在时核对旧配置）文件的 Windows 所有者能确认是当前用户时，才自动采用旧配置、代理和 data；未知、用户组或其他用户归属的资料留在原处，可通过已有原生导入能力明确选择，不能把共享安装目录当作当前用户的资料。新用户从安装包单独提供的只读 `config.defaults.yaml` 初始化，不能继承旧用户的可变配置；内核资源继续复用 chrome 布局。目录复制完整后才提交目标名称，失败停止启动，保留源及诊断用的临时副本。卸载保留各用户目录；旧安装目录遗留数据的清理仍须用户明确选择。

## 验证边界

离线测试使用临时公开 JSON、配置/SQLite/profile 文本 fixture、受控文件锁和既有进程边界；不运行产品、安装器、内核、真实登录或容器。CI 对现有 NSIS 做 fixture 编译，编译产物不执行。已有认证原生证据保持有效范围，新安装包实机安装/普通快捷方式启动尚未执行；不能用离线 PASS 代替这项运行记录。
